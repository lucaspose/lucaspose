#### 🚀 Projets phares

**[fvc](https://github.com/lucaspose/fvc)** — des microVMs [Firecracker](https://firecracker-microvm.github.io/) avec la simplicité de Docker, écrit en Go.
Un démon gRPC (`fvcd`, état en SQLite) et un CLI pour lancer, inspecter et exécuter des commandes dans de vraies machines virtuelles légères ; build d'images depuis un `Fvcfile`, conversion d'images Docker Hub en rootfs ext4, volumes, snapshots, réseau TAP/NAT, isolation via le jailer Firecracker et tests end-to-end sur KVM.

**[GopherCI](https://github.com/lucaspose/GopherCI)** — une plateforme CI/CD minimaliste écrite en Go.
Pool de workers concurrents qui clonent, buildent et testent des dépôts, suivi des jobs en temps réel (SSE), API REST sécurisée (JWT, contrôle d'accès, clés SSH chiffrées en AES-256-GCM), lancement en une commande avec Docker Compose.
Avec son client terminal interactif **[GopherCI-CLI](https://github.com/lucaspose/GopherCI-CLI)** (Bubble Tea).
